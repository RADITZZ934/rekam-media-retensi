# Development Rules

## Backend

* Gunakan Service Layer (jangan logic di controller)
* Gunakan Eloquent relation

## Frontend

* Vue 3 composition API
* Pisahkan page & component

## Naming

* snake_case (database)
* camelCase (JS)

## Flow Rule

* OCR → VALIDASI → SAVE
* Tidak boleh skip validasi

## Error Handling

* Gunakan try-catch
* Simpan error_log di database
